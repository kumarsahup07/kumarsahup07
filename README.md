<summary><b>FogGuard: Edge AI Wearable for Freezing of Gait Detection</b> &nbsp;|&nbsp; Top 20 Global Finalist, Silicon Labs IoT Challenge 2026</summary>
<br/>

**Problem.** Freezing of Gait (FoG) episodes in Parkinson's patients cause sudden loss of movement and increase fall risk. Detection has to run on the device, in real time, with very limited compute.

**Approach**
- Built an Edge AI wearable designed to detect and help prevent FoG episodes.
- Engineered lightweight inference pipelines that process multi-axis inertial sensor streams in real time.
- Selected among 136 teams and 650+ participants across 70+ universities worldwide.

**Stack:** Python, Edge AI, Embedded ML, Signal Processing, IoT
